Ado song ranker

A simple ranking game specially made for indecisive people.

Saved on this device only. Your progress lives in this browser's local storage. It never leaves your device, and clearing browser data erases it. Use Export to back it up or move it elsewhere.

This is not the main tier list. It's a guide for when you're struggling to rank. Use it to untangle close calls, then build your real list however you like.

1. Song list

Paste titles, one per line. Duplicates are ignored. Or load the sample set of songs as a starting point (complete discography, including covers and a few live/karaoke).

2. Battles

Pick the one you prefer. Tie or skip if you can't decide.

3. Close call helper

Answer four questions to break a tie between two songs. The result is a suggestion, never applied automatically.

4. Tier list

Tap a song to select it, then use the bar at the bottom to move it earlier, later, to another tier, or back to unplaced. On desktop you can also drag songs, or use the arrow keys on a selected song. Position in a tier is its rank.
